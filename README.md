## 📌 Project Overview

The **AWS EC2 Cloud Security Homelab** is a hands-on cloud computing and cybersecurity project designed to develop practical skills in cloud infrastructure deployment, Linux server administration, network security, and security monitoring using Amazon Web Services (AWS).

This project focuses on deploying and managing an Ubuntu Linux server using Amazon EC2, configuring secure remote access through SSH key-based authentication, and hosting a custom website using the Nginx web server. Security measures were implemented through AWS Security Groups, Ubuntu UFW Firewall, and SSH authentication configurations to strengthen server security and restrict unauthorized access.

Additionally, Amazon CloudWatch was used to monitor server performance, including CPU utilization and network traffic, while AWS CloudTrail was used to investigate API activities, identify resource changes, and review EC2 instance deployment events.

The project provides practical exposure to cloud infrastructure management, system security hardening, and audit logging, supporting the development of foundational skills relevant to **Cloud Engineering, Cloud Security, and Security Operations Center (SOC) roles**.

### 🎯 Project Objectives

- **Cloud Infrastructure Deployment:** Deploy and configure an Ubuntu Linux virtual server using Amazon EC2.
- **Linux Server Administration:** Perform system updates, manage services, and configure the Nginx web server.
- **Network Security:** Configure AWS Security Groups and Ubuntu UFW Firewall to control inbound and outbound network traffic.
- **Secure Remote Access:** Implement SSH key-based authentication and review SSH security configurations.
- **Cloud Monitoring:** Monitor EC2 performance metrics using Amazon CloudWatch.
- **Security Auditing:** Analyze AWS CloudTrail events to understand API activity and resource management.
- **Technical Documentation:** Document the implementation process, security configurations, monitoring results, and troubleshooting activities.
